CaptureFlow v2.0.9
 
The first public release of CaptureFlow - a fast, clean media downloader for Windows.
 
What's inside:
- Download from YouTube, Facebook, Instagram & TikTok
- Batch downloads - paste many links at once, or load a .txt list
- Whole pages, profiles & playlists - no video-count limit
- Pick your resolution, up to 2K (1440p)
- Export captions / transcripts to .txt
- Smart queue: pause, resume, reorder, download-now, auto-retry
- Built-in Library with thumbnails and one-click re-download
- Light & dark themes, custom save folder, no ads, no watermarks
- Automatic in-app updates
 
How to install:
1. Download the installer below (for example CaptureFlow-Setup-2.0.9.exe).
2. Run it. If Windows shows "Windows protected your PC", click
   More info -> Run anyway (it is safe).
3. Open CaptureFlow and start downloading.
